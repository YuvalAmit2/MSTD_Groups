# MSTD_Groups
Codebase for "Product and Quotient Set Dominance in Finite Groups"

MSTD_Sage.ipynb is the Sage code for most computation.

The rest is devoted specifically to computing the number of balanced sets in a given dihedral group via an efficient dynamic algorithm and multithreading. For obtaining the necessary large dihedral groups (with $\leq 30$ vertices) this code was run on the University of Maryland HPC.
